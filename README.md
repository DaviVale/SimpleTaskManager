# Overview

Simple Task Manager is a console application written in Kotlin. It allows users to add tasks, view their task list, mark tasks as completed, and remove tasks. It also displays the number of completed and pending tasks.

I created this software to learn the basics of Kotlin and practice writing a program that interacts with the user. I wanted to understand how variables, classes, functions, loops, conditionals, and collections work together in a simple application.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

I used IntelliJ IDEA to write and test the program. I used the terminal to run commands and check my code. I also used Git for version control.

I wrote the program in Kotlin using JDK 25. The program uses the Kotlin standard library, including mutable lists and functions for reading user input. I did not use any external libraries.
